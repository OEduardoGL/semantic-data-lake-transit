# Technical Documentation

This directory contains only the technical documentation required to inspect the public pipeline artifacts.

Included documents:

- `arquitetura_pipeline.md`: end-to-end data and ML pipeline architecture.
- `schema_decisions.md`: relevant schema and design decisions.
- `final_table_enrichment.md`: deterministic enrichment applied to the Gold analytical table.
- `ml_v2_methodological_rules.md`: final ML task definition, anti-leakage rules and metrics.
- `reproducibility_matrix.md`: mapping between scripts, artifacts and evidence.
- `stack_versions.md`: target/runtime tool versions.
- `ontologia_transporte.ttl`: semantic model in Turtle format.
- `mapeamento_silver_ontologia.md`: mapping between Silver tables and semantic entities.
- `regras_semanticas.md`: semantic rules used by the pipeline and prompts.

Non-technical planning documents, private logs, meeting notes and presentation material are intentionally not published here.

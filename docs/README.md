# Documentação Técnica

Este diretório contém apenas a documentação técnica necessária para inspecionar os artefatos públicos do pipeline.

Documentos incluídos:

- `arquitetura_pipeline.md`: arquitetura end-to-end do pipeline de dados e ML.
- `schema_decisions.md`: decisões relevantes de schema e desenho.
- `final_table_enrichment.md`: enriquecimento determinístico aplicado à tabela analítica Gold.
- `ml_v2_methodological_rules.md`: definição final da tarefa de ML, regras anti-vazamento e métricas.
- `reproducibility_matrix.md`: mapeamento entre scripts, artefatos e evidências.
- `stack_versions.md`: versões-alvo e versões de runtime.
- `ontologia_transporte.ttl`: modelo semântico em formato Turtle.
- `mapeamento_silver_ontologia.md`: mapeamento entre tabelas Silver e entidades semânticas.
- `regras_semanticas.md`: regras semânticas usadas pelo pipeline e pelos prompts.

Documentos de planejamento, logs privados, notas de reunião e materiais de apresentação não são publicados aqui.

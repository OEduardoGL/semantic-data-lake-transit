# Prompt 2 - ML com Foco Gerencial (v2)

## Objetivo
Gerar codigo Python para treinar e avaliar um pipeline simples, reproduzivel e metodologicamente mais forte de Machine Learning sobre a `final_table` enriquecida de transporte, seguindo o fluxo:
`FinalTable -> features seguras -> previsao da proxima janela -> metricas -> agregados gerenciais`.

Esta versao existe para corrigir fragilidades observadas na rodada 1:
- `MAPE` inadequado para o target;
- underfitting por modelo e features fracos;
- risco de vazamento/trivializacao do target;
- ambiguidade sobre o horizonte de previsao.

## Objetivo duplo obrigatorio
O codigo gerado deve atender a dois objetivos ao mesmo tempo:

1. Validar tecnicamente a `final_table`
- confirmar que as features permitem treinar um modelo reprodutivel sem vazamento;
- avaliar um baseline e um modelo principal com split temporal correto.

2. Gerar valor gerencial
- produzir previsoes e agregados que permitam responder perguntas como:
  - quais linhas tendem a apresentar maior atraso previsto na proxima janela;
  - quais faixas horarias sao mais criticas;
  - quais veiculos apresentam maior instabilidade operacional.

## Contexto dos dados (Gold)
A `final_table` esta pronta e validada em `s3a://transport/gold/final_table`.

### Colunas disponiveis
Chaves e tempo:
- `event_dt` (date)
- `janela_5min` (timestamp)
- `cod_linha` (int)
- `cod_veiculo` (int)
- `id_empresa` (int)
- `viagem_sentido` (string)

Contexto espacial e operacional:
- `latitude_media` (double)
- `longitude_media` (double)
- `velocidade_media` (double)
- `gps_invalid_pct` (double)
- `qtd_eventos_gps` (bigint)
- `qtd_eventos_stop` (bigint)
- `max_satelites` (int)

Metricas de headway e target atual:
- `headway_observado_min` (double)
- `headway_referencia_min` (double)
- `atraso_aproximado_min` (double)

### Qualidade da Gold validada
- `row_count`: 375099
- `null_target_pct`: 0.1245%
- target_quality_status: `ok (<= 10%)`

## Definicao do target e horizonte preditivo
O target final do problema continua sendo:
- `atraso_aproximado_min`

Definicao semantica:
- `atraso_aproximado_min = max(0, headway_observado_min - headway_referencia_min)`

### Horizonte preditivo obrigatorio desta versao
O pipeline nao deve estimar o atraso da propria linha corrente.
Ele deve prever:
- o `atraso_aproximado_min` da **proxima `janela_5min` disponivel** para o mesmo par:
  - `cod_linha`
  - `cod_veiculo`

Regras:
- ordenar por `janela_5min`;
- dentro de cada grupo `cod_linha + cod_veiculo`, criar o target deslocado para frente (`t+1`);
- descartar apenas as linhas sem proxima observacao disponivel para o grupo;
- usar o nome `y_true` e `y_pred` nos artefatos finais, mas eles devem representar o target futuro (`t+1`).

## Politica obrigatoria de features

### Features permitidas
Podem ser usadas features contemporaneas seguras e features historicas defasadas, por exemplo:
- identificacao e contexto:
  - `cod_linha`
  - `cod_veiculo`
  - `id_empresa`
  - `viagem_sentido`
- tempo:
  - `hour(janela_5min)`
  - `minute(janela_5min)` se houver utilidade
  - `day_of_week(event_dt)`
  - `is_weekend`
- operacionais e espaciais da janela atual:
  - `velocidade_media`
  - `gps_invalid_pct`
  - `qtd_eventos_gps`
  - `qtd_eventos_stop`
  - `max_satelites`
  - `latitude_media`
  - `longitude_media`
  - `headway_referencia_min`
- historico defasado criado por `lag`/`rolling`, por exemplo:
  - `lag_1_velocidade_media`
  - `lag_1_gps_invalid_pct`
  - `lag_1_qtd_eventos_gps`
  - `lag_1_qtd_eventos_stop`
  - `lag_1_headway_observado_min`
  - `lag_1_atraso_aproximado_min`
  - medias moveis anteriores por `cod_linha` ou `cod_linha + cod_veiculo`

### Features proibidas
Nao usar como feature na mesma linha do target futuro:
- `atraso_aproximado_min` contemporaneo da linha-alvo
- `headway_observado_min` contemporaneo da linha-alvo
- qualquer coluna derivada diretamente de `atraso_aproximado_min` ou `headway_observado_min` na mesma linha do target
- qualquer agregado calculado com informacao do futuro

### Regra de interpretabilidade
Se houver codificacao de categorias:
- nao sobrescrever os IDs originais nos artefatos finais;
- `cod_linha` e `cod_veiculo` originais devem permanecer preservados em `predictions_df` e agregados.

## Requisitos obrigatorios do pipeline
1. Receber `df_final` como DataFrame `pandas`.
2. Ordenar temporalmente e construir o target futuro (`t+1`) por `cod_linha + cod_veiculo`.
3. Fazer limpeza minima segura:
- tratar nulos remanescentes;
- ajustar imputacao e codificacao somente no treino;
- nao ajustar preprocessamento no dataframe completo antes do split.
4. Criar features temporais e historicas simples quando fizer sentido.
5. Usar split temporal explicito, sem `shuffle`.
6. Treinar:
- um baseline simples;
- um modelo principal mais forte que regressao linear simples.

## Modelo principal
Preferir um modelo simples, forte e explicavel do `scikit-learn`, por exemplo:
- `HistGradientBoostingRegressor`; ou
- `RandomForestRegressor`

Restricoes:
- nao usar `LinearRegression` como modelo principal;
- nao usar deep learning;
- nao usar bibliotecas exoticas;
- nao depender de dados externos.

## Baseline obrigatorio
Incluir obrigatoriamente um baseline ingenuo e temporalmente correto:
- mediana historica do target futuro (`t+1`) por `cod_linha` + `faixa_horaria`

Regras:
- calcular baseline somente no treino;
- permitir fallback:
  - `cod_linha + faixa_horaria`
  - depois `cod_linha`
  - depois baseline global do treino

## Split temporal obrigatorio
Usar split temporal explicito, por exemplo:
- treino: ~70%
- validacao: ~15%
- teste: ~15%

Regras:
- ordenar por tempo;
- nao embaralhar (`shuffle=False`);
- evitar vazamento temporal;
- qualquer encoder, imputador ou agregado auxiliar deve ser ajustado apenas no treino.

## Metricas obrigatorias
Calcular obrigatoriamente no conjunto de teste:
- `MAE`
- `RMSE`
- `WAPE`

Opcional:
- `MedAE`

### Politica sobre `MAPE`
- `MAPE` nao deve ser metrica principal nesta versao.
- se for calculado, deve aparecer apenas como campo secundario e com comentario explicito de baixa interpretabilidade devido aos zeros no target.
